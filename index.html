Cara Memasang Google Apps Script (GAS)

Google Apps Script (GAS) bertindak sebagai pembaca folder Google Drive sekaligus sebagai database riwayat link terpusat.

  1. Buka Google Sheets (sheets.new) untuk membuat file Spreadsheet baru.
  2. Pada menu di atas, klik Ekstensi → Apps Script.
  3. Hapus semua kode yang ada, lalu Salin (Copy) & Tempel (Paste) kode Terbaru di bawah ini:
  1. Klik tombol Terapkan (Deploy) di pojok kanan atas → Deployment Baru (New deployment).
  2. Pilih jenis roda gigi Aplikasi Web (Web app).
  3. Pada "Akses", pastikan Anda memilih Siapa saja (Anyone). Lalu klik Terapkan.
  4. Berikan Izin jika diminta, lalu Salin URL Web App yang muncul ke dalam pengaturan admin di website ini.
